`Settings → Automations & Scenes → Blueprints → Import Blueprint`

## 🚀 Quick Import

All blueprints in this repository follow the standard Home Assistant blueprint format. To import any blueprint:

1. Copy the raw GitHub URL of the blueprint YAML file.
2. In Home Assistant go to **Settings → Automations & Scenes → Blueprints**.
3. Click **Import Blueprint** and paste the URL.
